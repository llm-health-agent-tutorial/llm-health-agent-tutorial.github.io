“Why have I been sleeping poorly this week?”

Most consumer wearables and health dashboards can show you the data behind that question, but they cannot answer it. LLM agents — language models that call functions, run analyses, and visualize results — offer a path to connect curated multimodal sensing features with inspectable, data-grounded answers. In this half-day, hands-on tutorial, you will build a working personal LLM health agent from a minimal scaffold, over the public GLOBEM sample (sleep, steps, phone use and time at home), in your browser with nothing to install.

What you'll do — and leave with

No prior LLM or agent experience required. We start with the basics (model, tool, agent and skill), then build an agent, write tools for it, and test how it improves.

What you will do

  • Build the agent loop yourself, and write health-specific tools the agent can call.
  • Ask real questions over wearable and smartphone data, and check each answer against the data.
  • Let the model rewrite one of its own skills, test the change on a case it never saw, and discuss evaluation and safety in a panel with invited guests.

What you will leave with

  • A working LLM health agent you build in your browser on public sensing data, with your code saved as a notebook.
  • A runnable codebase and design template you can adapt to your own research.
  • Simple checks for an agent’s answers: can every number be traced to the data, and does the answer go along with the user when the data disagree?
  • Advanced pages for self-study: stronger checks, fixes in the harness, and automated improvement.

The learning model behind the tutorial

A short-format, hands-on instantiation of Student–AI Collaborative Inquiry (SACI). Read the accepted paper (PDF).

Accepted · UbiComp/ISWC 2026 Education Forum Students and AI agents co-investigate multimodal sensing data through mutual interrogation, under instructor scaffolding. Explore the SACI learning model Hide the SACI learning model ⌄

Student–AI Collaborative Inquiry SACI

SACI pairs a student and AI agent as co-investigators. The student contextualizes, interrogates, and reflects on claims; the agent retrieves and computes evidence, forms hypotheses, and surfaces counter-evidence. Responsibility remains with the student and instructor. This tutorial applies the model to a public GLOBEM sample: participants question the agent’s answers against the data, and when the model proposes a change to its own instructions, the participant judges it.

Prerequisites & what to bring

The tutorial is built to be accessible to participants from non-LLM backgrounds while staying meaningful for those with prior experience.

Prerequisites

  • Basic Python: comfortable reading and editing a few lines of code.
  • No prior LLM or agent experience required — the teaching blocks include a concise primer.
  • Familiarity with wearable or behavioral data is helpful but not required; a cleaned public sample is provided.

What to bring

  • A laptop with an up-to-date web browser (Chrome, Edge, Firefox or Safari). Nothing to install: the hands-on runs on agentlab.zhihanjiang.com.
  • No API key needed — we provide model access for the session. You get a seat code at the tutorial.
  • If you can, open the page before 15:00, so it has loaded when the hands-on starts.

The dataset

The hands-on uses the official public sample of the GLOBEM dataset: 10 college students with a Fitbit and a phone-sensing app, about seven weeks each. Observed missing values stay missing, and no credentialed data access is required.

FAQ

Do I need prior LLM or agent experience?
No. The teaching blocks include a concise primer, and the guided exercises will include starter notebooks with fill-in-the-blanks plus reference solutions. Intermediate Python is the only real prerequisite.
Do I need an API key? Will it cost money?
No, and no. We provide model access for the session through the tutorial page, at no cost to you.
What do I need on my laptop?
Only a web browser. The hands-on runs in your browser at agentlab.zhihanjiang.com, including the Python code, so there is nothing to install.
Do I get to keep the code and data?
Yes. Tutorial code and original synthetic materials use the MIT License. The included public GLOBEM sample retains its upstream Apache-2.0 attribution and notices. Materials will be available here before the tutorial.
Is this clinical or medical training?
No. The tutorial builds research prototypes for sensor-data sensemaking. Outputs are exploratory, not validated medical guidance, and any deployment on humans (including self, family, or research participants) requires appropriate IRB review.
