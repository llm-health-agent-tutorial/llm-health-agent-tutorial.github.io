Hands-on Tutorial · Half-day

Prototyping Your Personal LLM Health Agent

From Multimodal Sensing Data to Actionable Health Insights
“Why have I been sleeping poorly this week?”

Dashboards show the data but can't answer it. Build an LLM agent that turns raw wearable, phone, and self-report streams into grounded, personalized answers.

In one half-day, you'll build & leave with:
Health-specific tools (retrieval, analysis, visualization) registered with an LLM agent
A runnable agent loop that answers open-ended questions over your data
Open-source code you can point at your own wearable & phone data afterward
A checklist to evaluate agents on faithfulness & safety — and see where they break
Half-day, hands-on
Bring a laptop · Python ≥ 3.10
No prior LLM experience needed
