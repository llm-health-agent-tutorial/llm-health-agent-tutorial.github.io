# Tutorial code and teaching materials

Open [AgentLab](https://agentlab.zhihanjiang.com/) for the current slides, editable Python exercises and AI helper. No installation or personal API key is required; participants receive a seat code for model access at the tutorial.

Participants can export their code and completed results as a Jupyter notebook and download the lab package and public sample data. See the [tutorial website](https://llm-health-agent-tutorial.github.io/) for the current schedule.

## Archived notebook edition

Earlier notebook materials are retained as historical assets. Their speaker lists, schedules and setup instructions are superseded by the current browser-based tutorial.
